# 主要功能要求（实现版）

针对设备数据规模增长、知识分散与故障诊断依赖人工经验的问题，采用 Python + FastAPI、React、LangChain/LangGraph 和火山引擎方舟构建工业运维系统，以水泵、电机为场景。

1. 接入设备状态与环境监测数据，通过消息队列及 asyncio 协程/队列解耦解析、计算和存储；提供事件幂等、错误重试与批量写入。
2. 按设备编号设计水平分片，支持近百张表的固定路由；通过周期聚合和 Redis 缓存优化典型查询，面向亿级数据与 50ms 查询目标设计后续压测。
3. 通过方舟 API Key 调用支持工具使用的模型；LangGraph 编排规划、执行、分析和工具反馈，提供任务步骤及结果流。
4. 导入运维文档，语义段落切片、嵌入与 Milvus 检索；会话保存上下文，MCP 汇集指标、告警和日志证据，输出根因假设与人工检查建议。
5. React 提供运行总览、设备管理、告警、知识库与运维助手，支持自然语言问题、进度、结果、证据和历史会话。

交付中的本地演示使用 SQLite、进程内缓存和关键词检索；真实基础设施连接通过环境变量启用。规模指标与模型效果需独立验证。
